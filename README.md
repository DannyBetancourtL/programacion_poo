Descripción del Proyecto
El presente proyecto tiene como objetivo desarrollar un pequeño sistema de gestión de mascotas utilizando dos enfoques de programación diferentes: Programación Tradicional y Programación Orientada a Objetos (POO). Ambos programas permiten registrar y mostrar la información básica de una mascota, considerando los siguientes datos:
Nombre
Especie
Edad
Programa 1: Programación Tradicional
La primera solución fue desarrollada utilizando variables y funciones, sin emplear clases ni objetos. El programa solicita al usuario los datos de una mascota mediante teclado y posteriormente muestra la información registrada de forma organizada. Este enfoque se basa en la división de tareas mediante funciones independientes para el registro y la visualización de los datos.
Programa 2: Programación Orientada a Objetos

La segunda solución fue desarrollada utilizando Programación Orientada a Objetos. Se implementó una clase denominada Mascota, la cual contiene los atributos nombre, especie y edad, así como los métodos mostrar_informacion() y hacer_sonido(). Además, se crearon dos objetos de la clase para demostrar el funcionamiento de los atributos y métodos definidos.

Reflexión sobre las Diferencias entre Programación Tradicional y Programación Orientada a Objetos.

Durante el desarrollo de ambos programas se pudo observar que la Programación Tradicional organiza el código mediante funciones y variables independientes, lo que resulta adecuado para aplicaciones sencillas y de pequeña escala. Sin embargo, a medida que un programa crece, puede volverse más difícil de mantener y organizar.

Por otro lado, la Programación Orientada a Objetos permite agrupar datos y comportamientos relacionados dentro de una misma estructura llamada clase. Esto facilita la reutilización del código, mejora la organización del programa y simplifica su mantenimiento. Además, conceptos como la abstracción, los objetos y los métodos permiten representar elementos del mundo real de una manera más natural y eficiente.

En conclusión, ambos enfoques son válidos para resolver problemas informáticos; sin embargo, la Programación Orientada a Objetos ofrece mayores ventajas cuando se desarrollan sistemas más complejos, ya que favorece la modularidad, la reutilización y la escalabilidad del software.
